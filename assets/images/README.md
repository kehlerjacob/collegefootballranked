## Image Optimization

Before uploading images to WordPress:
1. Resize to recommended dimensions
2. Compress using tools like TinyPNG or ImageOptim
3. Use WebP format for better performance (WordPress 5.8+ supports WebP)
4. Aim for file sizes under 200KB per image

## WordPress Integration

Once you have the images:
1. Upload to WordPress Media Library
2. Set as featured images for pages/posts
3. Or place directly in this directory for theme use
