Click any button below to see the interactive forms in action

How It Works

Simply add data-flowtrus-trigger="form-id" to any button or link on your website. When clicked, Flowtrus will open a beautiful multi-step form modal that guides users through the data collection process with validation, progress tracking, and a smooth user experience.

Integration

Add the Flowtrus SDK to your website's <head> section and initialize it with your forms. Check the browser console to see the submitted data (in debug mode).
