# College Football Ranked - Team Logos

Place your local logo image files (`.png` or `.svg`) directly into this directory.

### Naming Convention:
Match the team name in lowercase with hyphens:
- `georgia.png`
- `ohio-state.png`
- `texas.png`
- `alabama.png`
- `oregon.png`
- `michigan.png`
- `notre-dame.png`
- `clemson.png`
- `miami-fl.png`
- `penn-state.png`
- `usc.png`
- `tennessee.png`
- `lsu.png`
- `florida-state.png`

Any team that does not have a logo file present in this folder yet will automatically and seamlessly fall back to its official colored initials badge.
